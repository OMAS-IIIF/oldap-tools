# MediaLibraryObject {#sec:media-library-object}

Ein `MediaLibraryObject` ist ein Medienobjekt in der allgemeinen Medienbibliothek. Es muss nicht direkt ein Archivobjekt darstellen. Solche Medien werden vor allem für redaktionelle Inhalte, Illustrationen und Stories verwendet.

Der Unterschied zum [`ArchiveMediaObject`](#sec:archive-media-object): Ein `ArchiveMediaObject` gehört fachlich zu einem konkreten [`ArchiveObject`](#sec:archive-object). Ein `MediaLibraryObject` kann allgemeiner eingesetzt werden, zum Beispiel als Leadbild einer Story.

## Wann dieses Objekt verwendet wird {#sec:media-library-object-verwendung}

Verwenden Sie `MediaLibraryObject` für Medien, die auf der Plattform genutzt werden, aber nicht zwingend ein bestimmtes Archivobjekt dokumentieren:

- Leadbild einer [`Story`](#sec:story);
- Stimmungsbild für einen redaktionellen Beitrag;
- Foto einer Situation, Veranstaltung oder Personengruppe;
- allgemeines Illustrationsmaterial zur Plattform.

## Felder {#sec:media-library-object-felder}

| Feld | Bedeutung für die Erfassung |
| --- | --- |
| Aufnahmedatum | Wann das Medienobjekt aufgenommen, digitalisiert oder erstellt wurde. |
| Titel/Name | Anzeigename des Medienobjekts. Pflichtfeld. |
| Beschreibung | Was zeigt oder dokumentiert das Medium, und warum ist es für die Fasnacht relevant? |
| Urheber | Person, die das Medium fotografiert, gefilmt, aufgenommen oder erstellt hat. |
| Quelle/Provenienz | Herkunft oder Quelle des Mediums. |
| Lizenz | Rechteangabe für die Nutzung des Mediums. Pflichtfeld. |

## Beispiel {#sec:media-library-object-beispiel}

Eine Story über das Laternenmalen kann ein Foto aus einer Werkstatt als Leadbild verwenden. Dieses Foto ist nicht zwingend ein Archivobjekt, sondern ein Medienobjekt der Bibliothek.
