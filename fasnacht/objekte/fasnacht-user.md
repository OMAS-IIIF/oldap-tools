# FasnachtUser {#sec:fasnacht-user}

Ein `FasnachtUser` ist ein Benutzerkonto für das Fasnachtsprojekt. Es erweitert das allgemeine OLDAP-Benutzerkonto um einen Organisationsbezug.

## Wann dieses Objekt verwendet wird {#sec:fasnacht-user-verwendung}

Verwenden Sie `FasnachtUser`, wenn eine Person im System arbeiten darf und fachlich eingeordnet werden soll, aus welchem Organisationstyp oder Organisationsumfeld sie kommt.

Das ist besonders nützlich, wenn mehrere Cliquen, Archive, Museen oder andere Institutionen Material beitragen und ihre Zuständigkeiten nachvollziehbar bleiben sollen.

## Felder {#sec:fasnacht-user-felder}

| Feld | Bedeutung für die Erfassung |
| --- | --- |
| Mitglied von Organisation | Optionale Zuordnung zu einem Eintrag aus der Organisationstaxonomie, zum Beispiel Clique, Archiv oder Museum. Es kann höchstens eine solche Zuordnung geben. |

## Beispiel {#sec:fasnacht-user-beispiel}

Eine Benutzerin arbeitet im Umfeld eines Archivs. Ihr Benutzerkonto kann mit der passenden Kategorie aus der Organisationstaxonomie verbunden werden, damit Beiträge und Zuständigkeiten besser eingeordnet werden können.
